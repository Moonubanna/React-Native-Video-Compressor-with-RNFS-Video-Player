# React Native Video Compressor with RNFS & Video Player

A demo/reference project for video capture, compression and playback in React Native using `react-native-fs` (RNFS) and a video-player component — built to showcase working flows in real apps.

---

## 🎬 What this project does

- Captures or selects a video file in a React Native app.  
- Saves the video using `react-native-fs` (RNFS).  
- Compresses/re-encodes the video (or integrates with compression flows).  
- Then plays the processed video via a UI component (video player).  
- Designed as a practical sample of how to integrate these flows in React Native mobile apps (iOS & Android).
